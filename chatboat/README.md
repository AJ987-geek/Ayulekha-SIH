# 🌿 AyuLekha - Intelligent Healthcare & Wellness Assistant

**AyuLekha** is an intelligent AI healthcare assistant powered by **[TinyFish AI](https://agent.tinyfish.ai/home)**. Whenever someone feels sick or experiences any health problem, AyuLekha **immediately delivers a complete, step-by-step actionable recovery and relief plan**—without asking tedious question surveys.

---

## 🌟 Key Features

1. **Direct, Immediate Actionable Solutions**
   - **No questionnaires / No delays**: As soon as you describe your problem, AyuLekha directly tells you **what to do right now** step-by-step.
   - Includes:
     - 🩺 **Clinical Explanation:** What is happening in the body.
     - ⚡ **Immediate Action Plan:** Step-by-step instructions to follow today.
     - 🍵 **Proven Home Remedies:** Ingredients, preparations, and daily frequency.
     - 💊 **Safe OTC Medicine Dosages:** Recommended medications with safety limits.
     - 🥗 **Diet & Lifestyle Guidelines:** What to eat/drink, and what to avoid for 48 hours.
     - 🚨 **Red Flags & Warnings:** When to see a doctor immediately.

2. **Emergency Red Flag Interception**
   - Instant safety checks for life-threatening symptoms (e.g. crushing chest pain, severe breathlessness, stroke signs / F.A.S.T, severe bleeding).
   - One-click direct emergency dialing (911 / 112).

3. **TinyFish AI Web Agent Integration (`https://agent.tinyfish.ai`)**
   - Uses TinyFish Web Intelligence to query up-to-date medical references and verified clinical facts.

4. **Speech & Consultation Exporter**
   - **Speech-to-Text Dictation** via microphone and **Text-to-Speech playback**.
   - **Print / Save PDF** summary to take to your doctor's visit.

## 🚀 Running AyuLekha

```bash
# Start the server
npm start

# Or with auto-reload
npm run dev
```

Open your browser at **[http://localhost:3000](http://localhost:3000)**.
